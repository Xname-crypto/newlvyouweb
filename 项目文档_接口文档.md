# 智慧旅游综合服务系统 接口文档

## 一、接口概述

本系统采用前后端分离架构，前端通过Supabase JS SDK与后端服务通信，部分AI相关功能通过调用Django RAG API实现。

### 1.1 接口分类

| 类别 | 调用方式 | 说明 |
|------|----------|------|
| Supabase Database | supabase-js SDK | 数据库CRUD操作 |
| Supabase Auth | supabase-js SDK | 身份认证 |
| Supabase Storage | supabase-js SDK | 文件存储 |
| Supabase Realtime | supabase-js SDK | 实时订阅 |
| Edge Functions | REST API | 无服务器函数 |
| Django RAG API | REST API | AI对话服务 |

## 十二、Supabase Realtime 实时订阅

```typescript
// 订阅帖子变化
supabase
  .channel('posts-channel')
  .on('postgres_changes',
    { event: '*', schema: 'public', table: 'posts' },
    (payload) => { console.log(payload) }
  )
  .subscribe()

// 订阅通知变化
supabase
  .channel('notifications-channel')
  .on('postgres_changes',
    {
      event: 'INSERT',
      schema: 'public',
      table: 'notifications',
      filter: `user_id=eq.${userId}`
    },
    (payload) => { handleNewNotification(payload) }
  )
  .subscribe()

// 订阅在线状态
supabase
  .channel('presence-channel')
  .on('presence', { event: 'sync' }, () => {
    const state = channel.presenceState()
  })
  .subscribe()
```

## 十四、Django RAG API 接口

### 14.1 RAG对话接口

```
POST /api/rag/chat/
Authorization: Bearer <access_token>

Request:
{
  "user_input": string,
  "user_id": string,
  "messages": [
    { "role": "user" | "assistant", "content": string }
  ],
  "model"?: string,
  "provider_id"?: string,
  "enableWebSearch"?: boolean
}

Response:
{
  "response": string,
  "personality"?: object,
  "sources"?: array
}
```

### 14.2 知识库管理接口

```
# 获取知识库条目
GET /api/rag/knowledge/

# 添加知识库条目
POST /api/rag/knowledge/
{
  "content": string,
  "metadata": object
}

# 删除知识库条目
DELETE /api/rag/knowledge/<id>/

# 重新生成向量索引
POST /api/rag/rebuild-index/
```
